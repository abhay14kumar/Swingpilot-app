# SwingPilot Personal — Public Safe Shell

This repository is intentionally safe to publish as static application code.

It contains NO:
- trading history or holdings
- P&L or account balances
- Zerodha account identifiers
- uploaded broker reports
- personal names, email addresses, phone numbers, addresses or credentials
- API keys, passwords, tokens or secrets

User data is created/imported at runtime and stored in the browser's IndexedDB on the user's device.

IMPORTANT: Browser-local data can be lost if site data is cleared. Use the in-app JSON backup.
